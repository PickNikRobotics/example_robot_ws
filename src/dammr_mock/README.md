# dammr_mock

Mock robot configuration package for the dual arm mobile manipulator robot (DAMMR): a four-wheel mecanum base with a vertical spine, whose single carriage carries two six-axis arms and a head camera.

```bash
moveit_pro run -w <path to example_robot_ws> -c dammr_mock
```

Only mock hardware is supported. Passing any other `hardware_interface` to `urdf/dammr.urdf.xacro` fails the robot description build.

## Robot

| Part | Model |
| --- | --- |
| Base | 0.80 × 0.60 m deck, four 0.10 m radius mecanum wheels at x ±0.28 m, y ±0.26 m. `base_link` is at the center of the wheel axles. |
| Base pose | Three joints from `world`: `linear_x_joint`, `linear_y_joint` (prismatic) and `rotational_yaw_joint` (continuous), in `urdf/dammr_virtual_base_joints.xacro`. |
| Spine | `spine_joint`, prismatic, 0–0.85 m, on a column at the rear of the deck. At 0 the arm mounting plane is 0.48 m above the floor. |
| Arms | Two `example_arm_description` arms, prefixed `left_` and `right_`, standing on the carriage at y ±0.275 m. The right arm is the mirror image of the left, so both upper arms sit outboard and the same joint values put the arms in mirror-image poses. Frames stay right-handed, so on the right arm the x axis of `right_ft_frame` and `right_tool0` points opposite to the mirror image of the left one, and under mirror-image loads the right sensor reports force x and torques y and z with the opposite sign to the left one. Each has a built-in wrist force/torque sensor, `<side>_tcp_fts_sensor`, at `<side>_ft_frame`. |
| Grippers | Parallel jaw with compliant fingertips. `<side>_finger_joint` is the travel of each finger toward the center: 0 is open (0.10 m between the contact faces) and 0.045 is closed. The tool center point is `<side>_grasp_link`. The right gripper is turned half a turn on its flange so that it mirrors the left one. On the right gripper the y axis of `right_grasp_link` is flipped relative to the mirror image of the left one, and `right_finger_link` sits outboard where `left_finger_link` sits inboard. |
| Head camera | `head_camera_link`, 0.327 m above the carriage and pitched 25° down. |
| Wrist cameras | `<side>_wrist_camera_link` on each gripper, tilted 20° toward the fingertips. |
| Lidars | 2D lidars `front_left_lidar_link` and `rear_right_lidar_link` on opposite deck corners, each facing diagonally outward. |

Each camera has a REP-103 `<name>_optical_frame`. Mock mode publishes no camera or lidar data. The intended sensor envelopes, for a later simulation config, are:

| Sensor | Depth field of view (H × V) | Range | Baseline |
| --- | --- | --- | --- |
| Head camera | 90° × 65° | 0.25–5 m | 50 mm |
| Wrist camera | 90° × 65° | 0.05–1.0 m | 18 mm |
| Lidar | 270° | | |

The fingertip meshes are generated by `scripts/generate_compliant_finger_meshes.py`.

## Planning groups

| Group | Joints |
| --- | --- |
| `left_arm`, `right_arm` | One arm |
| `both_arms` | Both arms |
| `spine` | `spine_joint` |
| `left_arm_spine`, `right_arm_spine` | Spine and one arm |
| `both_arms_spine` | Spine and both arms (the default group) |
| `base` | The three base pose joints |
| `whole_body` | Base, spine and both arms |
| `left_gripper`, `right_gripper` | One gripper |

Pose IK is configured for `left_arm`, `right_arm`, `left_arm_spine` and `right_arm_spine`. Most core Objectives default `joint_group_name` to `manipulator`, which this robot does not define, so set it on every core Objective you run.

## Objectives and waypoints

| Objective | Action |
| --- | --- |
| `Move Home` | Moves `both_arms_spine` to the `Home` waypoint: spine at 0.3 m, both grippers pointing down in front of the base, inside the head camera's view. |
| `Spine Up`, `Spine Down` | Moves `spine` to the `Spine Up` (0.85 m) or `Spine Down` (0) waypoint. |
| `Open Left Gripper`, `Close Left Gripper`, `Open Right Gripper`, `Close Right Gripper` | Sends one gripper to 0 (open) or 0.045 (closed). |

## Controllers

| Controller | Group or joint | State at startup |
| --- | --- | --- |
| `joint_trajectory_admittance_controller` | `whole_body`; executes trajectories for any group | Active |
| `left_gripper_controller`, `right_gripper_controller` | `<side>_finger_joint` | Active |
| `left_force_torque_sensor_broadcaster`, `right_force_torque_sensor_broadcaster` | `<side>_tcp_fts_sensor` | Active |
| `left_velocity_force_controller`, `right_velocity_force_controller` | Pose Jog for `left_arm`, `right_arm` | Inactive |
| `joint_velocity_controller` | Joint Jog for `whole_body` | Inactive |

The wheel joints take velocity commands, but no controller drives them: the base moves only through its three pose joints.
